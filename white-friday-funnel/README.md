# 🎯 منصة عروض الجمعة البيضاء - الهدف الأمثل

منصة Funnel تفاعلي ذكي بأسلوب Temu للخدمات التسويقية. يبدأ العميل بخيار دخول رخيص (Hook) ثم تظهر له وفورات إضافية عند إضافة خدمات مكملة أو الالتزام بفترات فوترة أطول.

## ✨ المميزات الرئيسية

- **Funnel تفاعلي ذكي**: رحلة مستخدم تدريجية من 4 خطوات
- **منطق Unlock ديناميكي**: تفتح الخدمات تدريجياً حسب الاختيارات
- **حاسبة توفير حية**: خصومات تصل إلى 35% للالتزام السنوي
- **تكامل واتساب**: إرسال مباشر لملخص الطلب
- **تصدير PDF**: توليد عرض احترافي قابل للطباعة
- **LocalStorage**: حفظ تقدم المستخدم
- **RTL كامل**: واجهة عربية 100%
- **تصميم Dark Gradient**: مع لمسات Neon أنيقة
- **متجاوب تماماً**: من 360px إلى 1440px

## 🔄 رحلة المستخدم (Funnel)

### الخطوة 1: اختيار المجال
- عرض 6 قطاعات مع أيقونات تعبيرية
- انتقال سلس للخطوة التالية

### الخطوة 2: اختيار المدينة
- 4 مدن رئيسية: المدينة المنورة، الرياض، جدة، مكة
- بطاقات تفاعلية

### الخطوة 3: أسئلة إضافية
- "هل لديك موقع؟"
- "هل تدير السوشيال بانتظام؟"
- اختيارات نعم/لا بتصميم أنيق

### الخطوة 4: الباقات والعروض
- **Hook Bundle**: محدد تلقائياً بسعر جذاب
- **Unlock Bundles**: تظهر تدريجياً
- **SavingsBar**: شريط توفير حي يتحدث مع الاختيارات
- **Billing Period**: اختيار مدة الفوترة (1/3/6/12 شهر)
- **Pricing Summary**: ملخص شامل مع التوفير

## 💰 نظام الخصومات

```json
{
  "m1": 0%,     // شهر واحد
  "m3": 10%,    // 3 أشهر
  "m6": 18%,    // 6 أشهر
  "y12": 35%    // 12 شهر
}
```

**مثال حسابي:**
- 3 خدمات × 5000 ر.س = 15,000 ر.س
- التزام 12 شهر: 180,000 ر.س
- خصم 35%: -63,000 ر.س
- **الإجمالي: 117,000 ر.س**
